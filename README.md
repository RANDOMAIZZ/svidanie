# 💖 Приглашение на свидание — Пятигорск

Сайт-приглашение:
1. «Пойдёшь со мной на свидание?» — кнопка **Нет убегает** (десктоп + мобайл).
2. Опрос: куда пойдём, где гуляем.
3. Яндекс.Карта — клик ставит метку, адрес + координаты уходят тебе на почту.
4. Отправка ответа на email `bogdanrandomaizzer@gmail.com` через FormSubmit + fallback mailto.

## Как запустить локально
Открой `index.html` или:
```bash
python -m http.server 8000
# http://localhost:8000
```

## Как включить письма на почту (1 раз!)
1. Залей сайт на GitHub Pages (инструкция ниже).
2. Открой сайт и отправь тестовый ответ.
3. Зайди на `bogdanrandomaizzer@gmail.com` — будет письмо от FormSubmit «Activate».
4. Нажми Activate. Всё, дальше все ответы будут приходить сами с темой «💖 Свидание!».

Письмо содержит: имя, куда, свой вариант, адрес, координаты, ссылку `https://yandex.ru/maps/?pt=lon,lat`, дату/время, пожелание.

## Залить на GitHub Pages
```bash
git init
git add .
git commit -m "date invite 💖"
gh repo create svidanie-pyatigorsk --public --source=. --push
# затем: Settings → Pages → Deploy from branch → main → / (root)
```
Ссылка будет: `https://ТВОЙ_НИК.github.io/svidanie-pyatigorsk/`

Отправь эту ссылку ей 💌

## Яндекс.Карты
Работает без API-ключа (лимит бесплатный). Центр — Пятигорск `[44.0486, 43.0594]`.
Пресеты: Цветник, Канатка, Эолова арфа, Провал. Можно тыкать в любое место — геокодер подтянет адрес.
