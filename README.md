# 💖 Приглашение на свидание — Пятигорск

Сайт-приглашение:
1. «Пойдёшь со мной на свидание?» — кнопка **Нет убегает** (десктоп + мобайл).
2. Опрос: куда пойдём, где гуляем.
3. Яндекс.Карта — клик ставит метку, адрес + координаты уходят тебе на почту.
4. Отправка ответа на email `bogdanrandomaizzer@gmail.com` через FormSubmit + fallback mailto.

## Как запустить локально
Открой `index.html` или:
```bash
python -m http.server 8000
# http://localhost:8000
```

## Ответы через Google-форму (рекомендуется)
1. Создай форму на forms.google.com с вопросами (все — «Краткий ответ»):
   Куда / Свой вариант / Где / Когда / Комментарий.
2. Вкладка «Ответы» → ⋮ → «Получать уведомления о новых ответах по эл. почте».
3. Скопируй ID формы из ссылки `docs.google.com/forms/d/e/ID/viewform`.
4. Для каждого вопроса: ПКМ по полю → «Просмотреть код» → `name="entry.XXX"`.
5. Вставь ID и entry в `script.js` (блок GOOGLE_FORM). Пока стоят заглушки —
   сайт шлёт через FormSubmit, после заполнения переключится на Google.

Письмо содержит: имя, куда, свой вариант, адрес, координаты, ссылку `https://yandex.ru/maps/?pt=lon,lat`, дату/время, пожелание.

## Яндекс.Карты
Работает без API-ключа (лимит бесплатный). Центр — Пятигорск `[44.0486, 43.0594]`.
Пресеты: Цветник, Канатка, Эолова арфа, Провал. Можно тыкать в любое место — геокодер подтянет адрес.
